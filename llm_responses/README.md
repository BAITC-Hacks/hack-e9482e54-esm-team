# Записанные ответы LLM

Эти JSON — неизменённые ответы `gpt-4.1-mini`, полученные в разрешённых
онлайн-прогонах на синтетических данных участника. Внутри только выбор
следующих экспериментов и объяснение модели; нет ключей, ID абонентов,
истинных эффектов или внутренностей среды.

Имя файла — SHA-256 сериализованного запроса Responses API, включая модель,
промпт, JSON-схему, кандидатов, наблюдаемые результаты пилотов и лимиты.
Ответ применяется только при точном совпадении запроса. Новые наблюдения
меняют хеш; при промахе агент обращается к API или использует резервную логику.

Папка входит в воспроизводимый комплект решения. Она обеспечивает повтор
известного прогона `make_submission.py` без сети и без пользовательского кэша.
Это сохранённые решения о пилотах, а не подставленный финальный CSV.
